# Sistema de Controle de Entrega

## 📌 Descrição
Sistema simples desenvolvido em Java para controle de entregas, contendo autenticação, cadastro de mercadorias e endereços, além da vinculação entre eles.

## 📦 Funcionalidades

- Login do usuário
- Cadastro de mercadorias (5 campos mínimos)
- Cadastro de endereço
- Vinculação 1:1 entre mercadoria e endereço

---

## 🌿 Fluxo Git Utilizado

1. Criação do repositório sem README inicial
2. Criação da branch `release-dev`
3. Desenvolvimento completo realizado na branch `release-dev`
4. Realização de múltiplos commits (mínimo de 5)
5. Criação de Pull Request
6. Merge da branch `release-dev` na branch `main`

---

## 🔀 Estrutura de Branches

- main → branch final
- release-dev → desenvolvimento

---
